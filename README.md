# Survival ML Starter

เรียนรู้ Machine Learning (Reinforcement Learning) ผ่านเกม survival จิ๋ว
AI ตัวนี้เริ่มจากเดินสุ่ม แล้วค่อย ๆ เรียนรู้ว่า "ต้องไปหาอาหารก่อนพลังงานหมด"

## รัน

```bash
pip install numpy
python train.py
```

ใช้เวลาประมาณ 1.5 นาที ผลที่ได้ (จากการรันจริง แผนที่ 5x5 มีอาหาร + บ่อน้ำที่มุมขวาล่าง):

| agent   | อยู่รอด (จาก 100 step) | อาหารที่กิน |
|---------|------------------------|-------------|
| สุ่ม     | ~15                    | ~0.3        |
| เทรนแล้ว | ~73                    | ~12         |

เทรนแล้วยังไม่สมบูรณ์ (ตัวเลขยังขึ้นอยู่) เพราะ state ใหญ่ขึ้นมากหลังเพิ่มน้ำ
ลองเพิ่ม `EPISODES` ดู หรือนี่คือจุดที่ควรย้ายไปใช้ Neural Network (DQN)

## ไฟล์

- `survival_env.py` — โลกของเกม (grid, พลังงาน, อาหาร, reward)
- `train.py` — เทรนด้วย Q-learning + เทียบกับ agent สุ่ม + demo

## แนวคิดหลัก 4 อย่าง

1. **State** — สิ่งที่ AI "เห็น": ตำแหน่งตัวเอง, ตำแหน่งอาหาร, พลังงาน, น้ำ
2. **Action** — สิ่งที่ทำได้: ขึ้น/ลง/ซ้าย/ขวา
3. **Reward** — ตัวชี้วัดว่าทำดีไหม: กินอาหาร +1, ตาย -5, ทุก step -0.05
4. **Q-table** — ตารางความจำ: "ใน state นี้ ทำ action ไหนแล้วได้ผลดีที่สุด"
   อัปเดตด้วยสูตรใน `train.py` (บรรทัด `Q[s, a] += ...`)

## ลองเล่นเพื่อเรียนรู้

- ตั้ง `EPS_START = 0.0` (ไม่สำรวจเลย) → AI จะติดแหง็ก เพราะไม่เคยลองอะไรใหม่
- ลด `EPISODES` เหลือ 5000 → เห็นว่าเรียนรู้ไม่ทัน
- ลด `GAMMA` เหลือ 0.5 → AI มองสั้น หาอาหารไกล ๆ ไม่เป็น
- แก้ reward: เอา death penalty ออก แล้วดูว่าพฤติกรรมเปลี่ยนยังไง
- เพิ่ม `size` เป็น 10 → Q-table ใหญ่ขึ้นมาก เรียนช้ามาก (นี่คือเหตุผลที่ต้องใช้ Neural Network)

## ต่อยอดให้ใกล้เกมจริง (ทีละขั้น)

1. ~~เพิ่มน้ำ~~ (ทำแล้ว: บ่อน้ำอยู่มุมขวาล่าง ดื่มไม่มี reward เพื่อกัน reward hacking)
2. เพิ่มศัตรู/สัตว์ป่าที่ต้องหลบ
3. เพิ่ม action: พัก, เก็บของ, ต่อสู้
4. เปลี่ยน Q-table เป็น Neural Network (DQN ด้วย PyTorch) เมื่อ state ใหญ่เกินตาราง
5. เชื่อมกับเกมจริง: ให้เกมเรียก `env.step()` ผ่าน socket/HTTP หรือ export โมเดลไปรันในเกม
   - ถ้าเป็น Unity → ML-Agents หรือ Barracuda/Sentis
   - ถ้าเป็น Godot → ส่ง state ไป Python ผ่าน WebSocket
   - ถ้าเป็น Python/pygame → import `SurvivalEnv` แล้วแทนที่ด้วยตรรกะเกมของคุณได้เลย
