# Survival ML Starter

เรียนรู้ Machine Learning (Reinforcement Learning) ผ่านเกม survival จิ๋ว
AI ตัวนี้เริ่มจากเดินสุ่ม แล้วค่อย ๆ เรียนรู้ว่า "ต้องไปหาอาหารก่อนพลังงานหมด"

## รัน

```bash
pip install numpy
python train.py
```

ใช้เวลาประมาณ 1.5 นาที ผลที่ได้ (จากการรันจริง แผนที่ 5x5 มีอาหาร + บ่อน้ำที่มุมขวาล่าง):

| agent   | อยู่รอด (จาก 100 step) | อาหารที่กิน |
|---------|------------------------|-------------|
| สุ่ม     | ~15                    | ~0.3        |
| เทรนแล้ว | ~73                    | ~12         |

## ขั้นถัดไป: DQN (Neural Network แทน Q-table)

```bash
python dqn_train.py
```

ใช้ numpy ล้วน (เขียน backprop เองให้เห็นทุกบรรทัด ไม่ต้องลง PyTorch) เทียบบนแผนที่เดียวกัน:

| วิธี | รอบเทรน | เวลา | อยู่รอด (จาก 100) | อาหาร |
|------|---------|------|--------------------|-------|
| Q-table (`train.py`) | 600,000 | ~85 วินาที | ~73 | ~12 |
| DQN (`dqn_train.py`) | 3,000 | ~22 วินาที | ~72 | ~15 |

DQN เรียนรู้จากประสบการณ์น้อยกว่าราว **200 เท่า** เพราะ network "สรุปรวม" ได้
(เจอสถานการณ์ใกล้เคียงกันก็ใช้ความรู้ร่วมกัน) ขณะที่ Q-table ต้องเจอทุก state เอง
ยิ่งโลกใหญ่ ความต่างยิ่งมาก

สังเกต: ทั้งสองวิธีไปหยุดที่ ~73 เหมือนกัน แม้เทรนนานขึ้น (ลอง 8,000 รอบก็ได้ ~74)
น่าจะเป็นเพราะเพดานจากการออกแบบแผนที่ (เช่นอาหารเกิดไกลบ่อน้ำจนรอดไม่ได้) ไม่ใช่ AI ไม่เก่ง
ผมยังไม่ได้พิสูจน์ข้อนี้ — เป็นการบ้านที่ดี: เขียนสคริปต์นับว่ามีกี่กรณีที่ "รอดไม่ได้ในทางทฤษฎี"

## ไฟล์

- `survival_env.py` — โลกของเกม (grid, พลังงาน, น้ำ, อาหาร, reward)
- `train.py` — เทรนด้วย Q-learning (ตาราง) + เทียบกับ agent สุ่ม + demo
- `dqn_train.py` — เทรนด้วย Neural Network (DQN, replay buffer, target network)

## แนวคิดหลัก 4 อย่าง

1. **State** — สิ่งที่ AI "เห็น": ตำแหน่งตัวเอง, ตำแหน่งอาหาร, พลังงาน, น้ำ
2. **Action** — สิ่งที่ทำได้: ขึ้น/ลง/ซ้าย/ขวา
3. **Reward** — ตัวชี้วัดว่าทำดีไหม: กินอาหาร +1, ตาย -5, ทุก step -0.05
4. **Q-table** — ตารางความจำ: "ใน state นี้ ทำ action ไหนแล้วได้ผลดีที่สุด"
   อัปเดตด้วยสูตรใน `train.py` (บรรทัด `Q[s, a] += ...`)

## ลองเล่นเพื่อเรียนรู้

- ตั้ง `EPS_START = 0.0` (ไม่สำรวจเลย) → AI จะติดแหง็ก เพราะไม่เคยลองอะไรใหม่
- ลด `EPISODES` เหลือ 5000 → เห็นว่าเรียนรู้ไม่ทัน
- ลด `GAMMA` เหลือ 0.5 → AI มองสั้น หาอาหารไกล ๆ ไม่เป็น
- แก้ reward: เอา death penalty ออก แล้วดูว่าพฤติกรรมเปลี่ยนยังไง
- เพิ่ม `size` เป็น 10 → Q-table ใหญ่ขึ้นมาก เรียนช้ามาก (นี่คือเหตุผลที่ต้องใช้ Neural Network)
